Chrome 扩展

标签组管理器

按窗口整理标签页：分组优先、只展开一个分组、新标签进入当前展开的分组。

v–

布局规则

自动应用在每个普通窗口。

标题点击

控制点击分组标题时的焦点变化。

选择“收起并展开默认分组”时，点击默认分组本身不会改变分组；没有默认分组时保持当前分组。

新标签页

决定新打开的标签页进入哪个分组。

Ctrl+T 和地址栏新标签页始终进入当前展开分组；页面链接保持 Chrome 默认行为。

默认分组

未分组标签页的归宿。

修改名称或颜色时，现有默认分组会同步重命名。

快捷键

随时回到默认分组。

切换到默认分组 读取中…

Chrome 不允许扩展直接修改快捷键；点击“更改”会打开 Chrome 的扩展快捷键页面。 默认建议 Alt+W。

钉住的分组

按标题和颜色识别；同标题同色的分组会一起钉住。列表顺序即标签栏顺序。

    还没有钉住的分组。

    Chrome 不提供禁止删除分组的 API。钉住通过“始终保持非空”实现：最后一个标签页关闭后， 扩展会用同标题、同颜色的分组重建一个未激活的空白新标签页。真实标签页不会被重新打开。

    钉住顺序始终生效；由于排序会把所有分组放到未分组标签页之前，因此钉住顺序同时意味着“分组在前”。

    立即整理

    重新应用分组排序、默认分组和单展开规则。
