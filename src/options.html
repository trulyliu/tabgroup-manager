Pinned groups

Matched by title and color; groups with the same title and color are pinned together. List order is tab strip order.

    No pinned groups yet.

    Chrome has no API to prevent deleting a group, so pinning keeps it from becoming empty: after its last tab closes, the extension recreates a group with the same title and color holding one inactive blank tab. Your real tabs are never reopened.

    Pinned order always applies. Because sorting puts every group before ungrouped tabs, pinning also implies “groups first”.
